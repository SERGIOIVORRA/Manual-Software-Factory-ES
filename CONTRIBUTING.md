# Contribuir

Mejoras bienvenidas a este manual.

## Cómo proponer cambios

1. Fork del repo
2. Rama `mejora/descripcion-corta`
3. Edita docs o plantillas en español
4. Abre Pull Request

## Criterios

- Textos claros y accionables
- Sin promocionar herramientas concretas como obligatorias
- Mantener el enfoque: factory = repetible + auditable + con contexto
- No añadir enlaces a vídeos o canales de terceros en el material base
